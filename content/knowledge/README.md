# LiveWell knowledge guides

These guides are original synthetic sample content for the LiveWell Coach workshop, written in an HPB-style plain-language voice for demonstration use. The markdown files in `livewell-guides/` are the source of truth; PDFs in `livewell-guides/pdf/` are generated by `python scripts/build-guides-pdf.py`. In Phase 4, `scripts/build-kb.py` uploads the PDFs to Blob storage and builds the Foundry IQ knowledge base `livewell-guides-kb` with knowledge source `livewell-guides-ks`.
